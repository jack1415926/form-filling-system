# 表单填报系统

面向公司内网电脑端的设计变更填报系统，将八张 Excel 工作表逐步转为网页填报，并支持多人并行审批及留言。技术栈：React、TypeScript、Vite、Ant Design、TanStack Query、Django REST Framework、MySQL 8.4。

## 当前进度

更新日期：2026-10-01。**阶段一实现及技术检查已完成，用户业务复验尚未完成，阶段一未关闭。**

[PR #1：落实草稿 ECR/ECO 编号唯一规则](https://github.com/jack1415926/form-filling-system/pull/1) 已创建，当前为 OPEN、尚未合并；功能提交 `81d3f2f`，目标分支 `main`。本轮文档整理不修改业务代码。

已实现：

- 登录、退出和单账号单有效会话；同浏览器多个窗口共享 Cookie，属于同一会话。
- 我的申请、新建概述草稿、11 个业务字段填写、保存及重新打开恢复；仅提交修改字段，失败保留输入，离开时提醒未保存内容。
- 用户数据隔离、系统字段只读、非草稿禁止修改，以及保存事务和行锁。
- 非空 ECR/ECO 编号分别全局唯一，空编号允许重复；接口校验及数据库约束覆盖并发写入，迁移前发现重复则停止并报告申请 ID。

未实现：删除申请、物料及其他工作表、提交审批、审批任务、留言和导出。

本机技术验证：28 项真实 MySQL 后端测试、Django 检查、迁移一致性、前端 lint/build 通过。此前 9 组浏览器回归证据保留在 `.local`；自制浏览器/Excel 工具已移除。测试范围及历史结果见 [复查记录](docs/testing/REVIEW-2026-09-30.md)，不代表用户验收或正式部署通过。

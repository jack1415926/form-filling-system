# 表单填报系统

将指定八张Excel设计变更工作表转为电脑端网页。React／TypeScript／Vite／Ant Design／TanStack Query，后端Django REST Framework和MySQL。

## 当前进度

2026-10-13：ECR至ECO三批闭环已技术交付，本轮审查修复与文档整理纳入源码交付。**用户业务验收、正式部署及其他设备数据库升级仍待完成。** 当前迁移0021，25张业务表。

| 范围 | 当前能力 |
| --- | --- |
| 基础与账号 | 概述、物料／处置、27题、EMC、计划、人工实质性评估、自动保存；同一账号发起及承担指定任务 |
| ECR与ECO | 各自的行动分配、冻结轮次、负责人填写／确认、整阶段退回、新轮重提、原作者复核、自动批准及指定发布 |
| 来源与进度 | 已发布ECR事务复制唯一关联ECO，修改互不影响；来源概述／结果只读，完整历史按原权限；六阶段导航 |
| 消息与反馈 | 任务／修订／复核／待发布、按账号持久已读；独立双向系统反馈，管理员处理 |
| legacy | 旧填写及整单指定审核、历史公开兼容；不自动转为任务，旧批准不视为发布 |

ECO“在实施阶段完成”只能保存，不能确认；编号分别非空全局唯一，ECO来源编号关联显示。发布不可撤销，关联ECO不能删除。详细准入、权限及恢复规则只维护在[MVP](docs/MVP.md)。

| 已修正问题 | 验证摘要 |
| --- | --- |
| 登录成功后仍停在登录页 | 只移除业务缓存并更新当前用户，登录/退出/重登通过 |
| 退出失败后丢失未保存提醒 | 真正离开或退出成功后才清除，失败保留输入和再次提醒 |
| 新建、保存与退出请求互相干扰 | 请求期间控件互斥，阻断请求复现及回归通过 |
| 测试库大小写同名保护遗漏 | `casefold()` 比较；实际 MySQL `lower_case_table_names=1`，配置测试拒绝同名 |
| 整表提交覆盖未修改字段 | 仅提交编辑字段；独立连接及页面修改不同字段均保留 |
| 2xx 非 JSON 被误认成功 | 拒绝无效响应，输入保留，恢复响应后重试通过 |
| 共享 Cookie 窗口重登后 CSRF 持续失败 | 写请求读取当前 Cookie；两窗口保存、退出通过 |
| 保存错误位置不明显 | 持久错误显示在保存按钮附近，失败输入保留 |
| 单账号保留多个登录会话 | 登录信号和用户行锁替换旧会话，覆盖应用及 Django 内置登录，不影响其他用户 |

## 人工复验流程

在 **http://localhost:5173** 使用 [开发说明](../DEVELOPMENT.md#启动与账号)中的演示账号复验并反馈：

1. 错误密码被拒绝，正确登录进入我的申请。
2. 对照真实 Excel 核对概述字段；保存、重开、刷新后再打开、退出重登后数据一致。
3. 单独修改字段及清空日期，其他内容保留；未保存时离开，取消保留输入，确认放弃后恢复原数据。
4. 非空同类型编号重复被拒绝，输入保留；多个空编号、编辑原编号及清空后复用可保存。
5. 同浏览器两窗口重登后，旧页面可保存/退出；两个页面修改不同字段均保留。
6. 独立浏览器重登同账号，旧端后续读取/保存被拒绝，未保存输入保留。
7. 请求期间控件保护、失败后恢复及保存按钮附近的错误提示正常；第二账号无法访问第一账号草稿。

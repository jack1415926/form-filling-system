# ECR内ECO模板详情样式

日期：2026-10-16。

用户反馈：ECR阶段ECO执行页的“查看模板”抽屉只有题号／职能和两段文字，空白较多，外观与正式行动填写页不一致。

仅调整InactiveEcoSheet的只读抽屉：宽度与ECO行动抽屉统一为720，使用现有Ant Design表单控件、form-grid及行动说明样式；顶部显示行动编号、来源问题、职能和当前问题答案，下面展示执行行动、负责人、执行结果／不适用原因、业务状态和业务日期。负责人／结果／状态／日期均为禁用空白模板，无保存、确认或分配操作，不引用真实ECO填写值，不调用自动保存。保留原筛选、查看全部模板、失败重试和权限边界。

验证：前端TypeScript／Vite构建、lint通过，保留既有包体积提示；独立MySQL浏览器环境验证全否题目下默认空列表、切换全部模板后打开问题1。抽屉显示编号eco_001、问题1、职能、行动描述及完整表单字段，负责人／结果／状态／日期和日期按钮均为disabled，仅能关闭预览。未新增UI单元测试或重跑全量／后端测试，本次没有后端或数据结构修改。

预览在本机`.local/eco-template-style/preview.png`，不提交Git。页面验证使用临时测试账号和独立测试库，不操作现有开发申请；临时网页服务及测试库在验证后清理。正常内网Vite服务已加载修改，刷新ECR中的“ECO执行 → 查看模板”即可查看。

# 测试精简及耗时对照

2026-10-02，仅调整后端测试，不修改业务代码、数据库结构或生产密码配置。

## 调整

- DraftFlowTests 与 MaterialFlowTests 通过类级 `override_settings` 使用 MD5PasswordHasher，只在该测试类运行期间生效；登录仍走真实认证、数据库会话、权限和 CSRF 流程，没有用 force_authenticate 替换这些功能测试。
- MaterialFlowTests 的两个公共用户移到 setUpTestData，一次创建；每项测试仍独立创建申请和 APIClient，使用 TestCase 的事务隔离。
- PATCH 缺少 CSRF 的拒绝及“不改数据”断言合并进登录／退出／POST 的 CSRF 测试。
- PUT 返回 405 的断言移入申请访问／删除保护测试；移除简单 DELETE 成功的重复检查，保留完整级联删除、编号复用及重复删除测试。
- 并发、锁等待、读取一致性、数据库约束和迁移测试均保留。原并发保存的 5 次重复仅约 0.074 秒，没有为降低数字而继续改动它。

## 确认的问题及修复

P2：已读接口在校验快照与写入之间没有和审核事件串行。两个页面并发时，旧消息请求可以在新回应及其已读完成后覆盖标记，导致已读的新消息重新显示红点。

隔离MySQL并发测试先暂停旧标记写入，再并发创建新回应并标已读。修复前最终unread_count为2而非0，测试失败，证明旧标记实际覆盖新标记。修复先核对目标申请属于本人可访问待处理范围，再按申请ID顺序取得与审核写入相同的父申请行锁，在锁内重新校验消息签名并保存。新回应及新已读不会被旧请求覆盖；陈旧签名仍拒绝，不修改批准或意见状态。复验最终unread_count为0。

同时适配既有浏览器辅助脚本的新统一菜单和登录提醒；恢复模拟显式提供空审核消息响应，避免把未配置模拟接口当产品故障。脚本语法检查通过，本机没有这些脚本要求的Playwright模块，原脚本未冒充已完整重跑；组件回归使用现有agent-browser/Edge独立模拟页面。

审查还核对日期全部写入口、草稿/未知状态跳转保护、指定/公开权限、退回正文隔离、已读账号隔离及CSRF。未确认其他产品正确性、安全或回归缺陷；公司首次按钮灰色仍没有原设备证据，本批不会宣称已找到其根因。

# 四项状态同步审查问题修复

日期：2026-10-03。范围为概述、申请详情缓存、问题评估及 EMC 的前端状态同步；未修改后端、迁移、权限或业务数据库。

## 修复结论

1. 问题与 EMC 原先在脏表单读取新数据时更新 `seen`，撤回修改后不会再采用已读取的新数据。删除该一次性观察标记，统一通过 `refreshBaseline` 在当前保护状态解除后重新判断最新读取；不需要再请求一次接口。
2. 申请详情 GET、概述保存回调及父级缓存写入统一采用 `newestResponse`。旧读取不能覆盖较新的保存，旧保存响应不能覆盖较新的读取，表单也采用实际选中的最新记录。
3. 问题 GET、PATCH 成功回调、表单基线及申请更新时间统一采用相同顺序规则；保留微秒精度，不再只比较 JavaScript 毫秒时间。
4. 概述以已采用的记录作为基线，基线改变时同步 Ant Design 表单和最近保存时间。干净表单可以原地刷新；脏表单、保存中及不完整日期不采用后台刷新。保存失败仍保留输入与待提交字段。

`refreshBaseline` 仅判断何时允许采用读取；未引入通用表单平台。问题与 EMC 的结果未确认字段仍参与补丁计算，因此即使改回原值，也不会误判为干净表单。

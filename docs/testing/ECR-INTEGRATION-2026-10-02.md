## 实现与边界

61 条 ECR 固定定义统一存于后端 JSON，正式 API 与内存演示共用，不重复维护题干。读取固定行动与已保存问题答案、已填结果；默认只显示当前触发或有填写的行动，可切全部查看。负责人、结果、评估状态及日期在单条抽屉填写、局部 PATCH 保存；未触发行动仍可填写，答案改变不删结果、不改为不适用。

新增 0007_ecractionresponse 及申请／行动唯一约束、合法行动及状态 CHECK。GET 列表和单条 PATCH 均锁申请，保证问题、行动及时间来自一致读取；权限、CSRF、预期账号、非草稿保护沿用现有机制。重试按稳定行动标识更新，不重复创建；全清空删除填写记录，不删除固定定义。

正式页不使用任何演示填写默认值。问题保存使 ECR 缓存失效；删除申请及换账号清理相应缓存，同账号重登刷新读取但不卸载正在编辑的抽屉。刷新失败保留已有列表和输入，较旧响应不覆盖新保存缓存；保存失败保留输入，结果不确定时保留待确认字段，改回基线仍允许重试。共有 beforeunload 和抽屉打开时页间导航保护保持。

## 数据与接口

0019_ecr_stage_tasks增加ChangeRequest.stage（legacy／ecr，迁移默认legacy）及publisher外键、EcrActionResponse.extra_required、ReviewRound.submission_payload，以及action_task、task_operation两张表。当前业务表为25张。迁移末尾设逆迁移守卫：有新阶段、任务或补充标记时，不直接回退丢失证据。

每项任务绑定轮次、稳定行动标识和负责人，保存结果／业务状态／日期、版本、确认时间；操作回执按任务／作者／UUID去重并校验原载荷。任务历史以对应轮次记录为准；当前行动填写表仅作当前值，在任务保存事务中同步。没有新增基础表逐轮完整快照。

新增接口：

| 接口 | 职责 |
| --- | --- |
| GET /api/changes/{id}/stage-workflow/ | 返回当前阶段、任务、可见历史、提交回执及阻止原因；修订期间参与者不读取私有正文 |
| POST /api/changes/{id}/stage-submission/ | 接收request_id、expected_round、acknowledge_no_tasks，校验保存内容并开启轮次 |
| PATCH /api/changes/{id}/action-tasks/{task_id}/ | 接收request_id、version及局部result／status／date，仅负责人可写当前未确认任务 |
| POST /api/changes/{id}/action-tasks/{task_id}/ | 仅接收request_id、version，确认已保存且完整的任务 |

新ECR原行动PATCH仅允许owner_user_id、extra_required；原submission／approve拒绝新ECR，其他基础保存接口保持本人draft／returned规则。状态不接受普通PATCH。publisher_id仅用于本批指定关系，尚无发布入口。

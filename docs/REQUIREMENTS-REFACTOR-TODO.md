- [ ] ECR：本人／他人任务权限，问题触发、补充与零任务，意见回应、新轮重新确认、历史及失败恢复。
- [ ] 发布与复制：发布授权、不可撤销、复制字段与独立编号、重复创建不覆盖草稿、ECO修订不影响来源。
- [ ] ECO：填写人交接、实施状态不能确认、改派后原作者复核、独立批准发布、六阶段及持久已读。
- [ ] 正式审核意见和完整轮次历史的实际业务场景。
- [ ] 独立系统反馈：用户提交／追加、管理员公开处理、关闭后追加重开、未读／已读及权限撤销的完整业务验收；第17页线框图已补齐，不据此视为验收完成。
- [ ] 另一台电脑实际访问；正式部署、其他设备迁移及恢复验证。

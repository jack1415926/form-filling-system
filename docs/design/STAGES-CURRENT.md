## 六阶段进度

```mermaid
flowchart LR
    A["ECR填写／修订"] -->|"提交：冻结任务及人员"| B["ECR任务处理"]
    B -->|"任务全部确认、意见解决、指定批准人全部同意"| C["ECR发布"]
    B -->|"整阶段退回"| A
    C -->|"原发起人或实际发布人创建，指定填写人"| D["ECO独立填写／修订"]
    D -->|"提交：新ECO轮次"| E["ECO任务处理"]
    E -->|"任务全部确认、意见解决、指定批准人全部同意"| F["ECO发布"]
    E -->|"整阶段退回"| D
    F --> G["流程完成：两实例只读"]
    C -.->|"来源概述与行动结果只读引用"| E
```

approved表示等待指定发布人操作；published表示发布完成。退回使本轮停止，新轮任务及批准重新计算；旧轮确认不计入修订进度。零任务明确确认后仍须全部所选批准人同意，批准后须显式发布。

## 人员与来源边界

| 内容 | 授权及行为 |
| --- | --- |
| 基础表、任务范围、负责人、发布人 | 当前填写人仅draft／returned编辑；至少指定一位批准人，提交后锁定 |
| 任务填写／确认 | 指定负责人处理自己的当前未确认任务，允许本人任务 |
| 实施阶段完成 | 可以保存，不能确认；完成／不适用须说明及日期完整 |
| 退回／回应／复核 | 任务负责人或指定批准人提出意见并退回本阶段；发起人逐条回应；原提出者复核，改派后保留职责 |
| 发布 | 每个实例自己的有效指定发布人，仅approved可操作，不能撤销 |
| ECO来源 | 基础数据独立复制；ECR结果只读引用；仅ECO参与者看来源概述与结果，不获得完整ECR历史权限 |
| 相邻阶段导航 | 仅有正文权限时开放；无权阶段隐藏编号／任务／历史，退回参与者走意见和历史入口 |
| ECO填写人及交接 | 可指定任意有效用户，包括自己；草稿／退回由原ECR发起人、实际发布人或当前填写人交接，保留内容及历史；原ECR人员只读跟踪 |

当前导航通过stage-navigation返回六节点摘要；source-ecr仅提供来源发布概述。旧轮任务和意见有独立访问校验，导航不是额外授权。

## 必要待办

任务未确认、退回修订、原作者复核和指定发布人待发布按当前阶段／轮次汇总；本人事项去重。已读只清提醒，不确认任务或执行发布；批准后出现待发布，发布后退出待办。完成广播通知不属于本批。

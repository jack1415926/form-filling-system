# 统一账号工作台 A／B 导航预览

日期：2026-10-12。属于第一步重构前的界面选型，用户已选择B版，正式第一步交付见[验证记录](../testing/DUAL-WORKSPACE-2026-10-12.md)。A版仅保留为独立历史原型，不接入正式产品。

使用同一份独立HTML提供两个预览页面，无外部依赖，无业务API，无数据库写入；刷新恢复虚拟数据。

- [A版：页签切换](http://127.0.0.1:5181/?variant=A&account=reviewer)。默认进入我的申请，直接切换待我处理。
- [B版：首页两个入口](http://127.0.0.1:5181/?variant=B&account=reviewer)。先选择要做的事情，再进入列表，支持返回工作台首页。

预览服务仅绑定本机127.0.0.1:5181。服务停止时可在项目根目录执行 `node .local/nav-prototype-server.cjs`；该本机辅助脚本不提交。也可以直接用浏览器打开 `workspace-navigation.html`，顶部切换A／B版。

## 可体验的内容

- 原审核员账号同时拥有本人申请及他人审核入口；普通账号仅显示本人申请。
- 新建虚拟草稿，填写标题、编号和原因，保存、返回和重开。
- 查看他人只读申请、打开意见入口、模拟记录个人同意、查看已处理记录；个人同意不把整单状态自动改为批准。
- 两版共用账号显示、意见与反馈入口及示例数据；演示账号切换不是正式产品操作。
- 未保存输入离开时可取消或确认放弃。

仅概述区域可交互，其他工作表名称用于表示详情页上下文；本原型不模拟完整八表、真实请求恢复、逐项任务、ECR／ECO独立流转或发布。
